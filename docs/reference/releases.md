# Releases

`CHANGELOG.md` is the authoritative history ([Keep a Changelog](https://keepachangelog.com) from
v1.1.0; the earlier entries keep the project's original prose headings). This page renders it as a
timeline; on the site you can filter by version, date or a word from the title. The release process
itself — one number across web, API and app, the tag cut only after a verified deploy — is on
[Release](../process/release.md) and [the delivery pipeline](../process/branching.md).
