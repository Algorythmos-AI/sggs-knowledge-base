# Brand and palette

**Gurbani Soul** is the app; this wiki and the website are separate, scholarly properties that
borrow its palette. Scripture is never branded: it is always *Sri Guru Granth Sahib Ji · Ang N*.

| Read | For |
|---|---|
| [The brand book](gurbani-soul-brand-book.md) | the gold rule, palette, typography, mark, voice, accessibility and the gates (G1–G4) |
| [The contrast report](contrast-report.md) | every required pair, in all four legs, generated by `scripts/brand/contrast_report.py` |
| [`tokens.json`](tokens.json) | the source of truth: surfaces, Soul Gold, brand and status colours, light · dark · increased contrast |

## The rules in one breath

- **Gold is a fill, never text.** The literal brand gold `#FFBC0D` measures 1.69:1 on white, so it
  appears only as `accentFill`, always with an `accent` border; text, icons and links use `accent`
  or `accentText`.
- **Red is fill-only** — badges, never text, never beside Gurmukhi — and never in a poster or a
  diagram on this wiki. Never a gold mark on a red square.
- **Gurmukhi is ink-coloured Sant Lipi**, never gold, never red. Headings use Source Serif 4.
- **Dark mode is warm ink**, not grey.

## The palette

On the rendered wiki this is every token in `tokens.json` — light and dark — with a swatch and its
contrast ratio, computed from the file at build. On GitHub, read [`tokens.json`](tokens.json) and the
[contrast report](contrast-report.md).

The wiki's own theme (`docs-site/src/styles/theme.css`) uses the same values for paper, card,
accent, accent text, accent fill and the status colours; the docs gates fail a pull request when
the two drift ([the docs gates](../contributing/docs-gates.md)).
