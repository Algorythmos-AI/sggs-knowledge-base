# Decisions

An ADR records one decision that shaped the system: the context, the decision, the consequences.
They are numbered in the order they were written and never edited after acceptance — a later
decision that changes course gets its own number and says so. The sibling repositories keep their
own ADRs ([sggs-data](../data/README.md#pinned-from-sggs-data),
[gurbani-soul-ios](../ios/README.md#pinned-from-gurbani-soul-ios)).

<!-- sggs:adr-timeline -->
On the rendered wiki this is a timeline; on GitHub, the records are the numbered files in this
directory.

## Writing one

Copy the newest record, take the next number, keep the three headings, and state the status with
its date (`**Status:** accepted (YYYY-MM-DD)`). [Exercise 04](../exercises/04-write-an-adr.md) walks
through it.
