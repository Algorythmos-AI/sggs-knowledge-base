## CHECK 3 — Sihari Sanity

### 3a: Pattern `ਿ[ ੍ਾੀੁੂੇੈੋੌੰਂ]` — 365 matches (FALSE POSITIVES)

The overwhelming majority (9,824 rows) show `ਿ` followed by a space — this is completely normal: sihari on a final consonant of a word before a word boundary. This is correct Gurmukhi.

The `ਿ` + `ੰ` pattern (e.g. `ਗੋਵਿੰਦ`, `ਪਿੰਡੁ`, `ਸਿੰਘੁ`) is also correct — these are inherently compound forms where sihari precedes a bindi/tippi on the same consonant (visual reordering of `ਗੋਵਿੰਦ` = ਗ+ੋ+ਵ+ਿ+ੰ+ਦ). 365 such matches; all appear linguistically normal.

**The original regex was too broad.** True errors require `ਿ` appearing before a consonant without a preceding consonant base, or as a standalone character.

### 3b: Leading/Standalone Sihari — **1 genuine anomaly** (FAIL for this line)

**id=31087, ang=727:**
```
ਅਸਮਾਨ ਿ◌ ਮ੍ਯ੍ਯਾਨੇ ਲਹੰਗ ਦਰੀਆ ਗੁਸਲ ਕਰਦਨ ਬੂਦ ॥
```

Codepoint analysis:
- Position 6: `U+0A3F` GURMUKHI VOWEL SIGN I (ਿ) — **standalone, no consonant base**
- Position 7: `U+25CC` DOTTED CIRCLE (◌) — a Unicode rendering placeholder used when a dependent vowel sign has no base consonant to attach to

**Judgment:** This is a defective encoding. The original line is a Persian/Farsi verse by Bhagat Kabir in Tilaṅg (one of several such verses at ang 727). The word that should appear here is `ਮ੍ਯ੍ਯਾਨੇ` (miyyāne, "in the middle/between"). The standalone `ਿ◌` before `ਮ੍ਯ੍ਯਾਨੇ` is a glyph-mapping artifact — the PDF source contained a `f02d` ligature glyph (a decorative form of the word `ਦਰਮ੍ਯਾਨੇ` meaning "between/in the midst") that was incorrectly split during OCR/extraction. The `ਿ` is an orphaned vowel sign that should either be part of the preceding consonant cluster or belongs to the word `ਦਰਮ੍ਯਾਨੇ`. The word as rendered is **wrong** — it should read `ਅਸਮਾਨ ਦਰਮ੍ਯਾਨੇ` or `ਮ੍ਯਾਨੇ` without the orphaned sihari.
